# bot-economy

Экономика для Discord: монеты, дейлик со стриком, работа, кейсы, ограбления,
дуэли, квесты, дропы в чате, сезоны и статистика активности.

## Что нужно для запуска

- Python 3.10+ и `pip install -r requirements.txt`
- Переменные окружения на хосте:
  - `DISCORD_BOT_TOKEN` — токен бота
  - `GUILD_ID` — id сервера (можно не задавать, тогда берётся `1573386089467748482`)
- В Developer Portal **не нужны** привилегированные интенты: бот живёт на дефолтных
  (`guild_messages`, `voice_states`), текст сообщений не читает.
- Права бота на сервере: `268520448`
  (View Channels, Send Messages, Embed Links, Read Message History, Manage Roles).
  Для продажи ролей роль бота должна стоять **выше** продаваемых.

## Первый запуск

1. Залить файлы, Restart в панели.
2. В канале «карзина» (или в том, что укажешь) выполнить:

```
/eco_config currency:🪙 daily_amount:250 max_bet:1000 channel:#карзина
/eco_config drop_channel:#общий drop_every:200
/shop_add role:@Роль price:5000
```

3. Проверить: `/balance`, `/daily`, `/work`, `/slots 100`.

## Канал экономики

Все игровые и денежные команды работают только в канале экономики.
Канал задаётся через `/eco_config channel:#...`; если не задан — бот ищет канал,
в имени которого есть «карзина»/«корзина». Админские команды (`eco_*`, `shop_*`)
работают в любом канале.

## Команды

**Деньги**
- `/balance [user]` — баланс, кулдауны, стрик
- `/daily` — дейлик, стрик до 7 дней даёт до +60%
- `/work` — подработка раз в час (50–150)
- `/pay user amount` — перевод
- `/top` — топ-10 богачей

**Азарт**
- `/slots bet` — три в ряд x10, два в ряд x1.5
- `/dice bet` — кости против бота, победа x1.9
- `/flip bet` — орёл/решка, угадал x1.9
- `/rps bet` — КНБ против бота, победа x2
- `/case [count]` — кейс за 500, внутри — от «пусто» до x10
- `/duel user bet` — дуэль на кнопках, победитель забирает банк
- `/rob user` — ограбление: шанс 40%, кулдаун 2 часа, попался — штраф x2

**Прогресс**
- `/quests` — три ежедневных квеста с кнопками «сдать»
- `/season` — сезонный топ по заработку за месяц
- `/stats [user]` — сообщения, время в войсе (сегодня/всего), игры, кейсы, кражи

**Магазин**
- `/shop`, `/buy role`
- `/shop_add role price`, `/shop_remove role` (manage_guild)

**Админ**
- `/eco_give`, `/eco_take`, `/eco_set` (administrator)
- `/eco_config` — валюта, дейлик, макс. ставка, каналы, частота дропов
- `/eco_stats` — монет в обороте, счета, активные сегодня, топы
- `/eco_season_end` — выдать призы топ-3 сезона (раз в месяц)
- `/eco_drop` — вручную устроить дроп

## Данные

Всё лежит в `data/` рядом с ботом (в git не попадает):

- `economy.json` — балансы и счётчики участников
- `shop.json` — роли в магазине
- `settings.json` — настройки сервера
- `stats.json` — сообщения и время в войсе (пишется раз в минуту)

Бэкап — просто скопировать папку `data/`.
